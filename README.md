# رَسا — پیش‌نمایش

این مخزن در حال توسعه است. فایل `index.html` فعلاً یک پیش‌نمایش تعاملی رابط پیام‌رسان (با گفتگوهای نمونه و حالت نمایشی) است؛ هنوز به Supabase متصل نیست و ورود/ارسال واقعی پیام فعال نیست.

## انتشار با GitHub Pages
در مخزن به Settings → Pages برو، در بخش Build and deployment گزینه Deploy from a branch را انتخاب کن، Branch را `main` و Folder را `/ (root)` بگذار و Save کن. پس از چند دقیقه سایت در این آدرس قابل دسترسی خواهد بود:

https://zmrmioeo-alt.github.io/rasa-messenger/

## وضعیت
- پیش‌نمایش رابط فارسی و واکنش‌گرا
- نمونه گفتگوها و ارسال پیام نمایشی در مرورگر
- رَسا‌لند به صورت بخش معرفی‌شده (هنوز در حال ساخت)
- نسخه اصلی با Supabase، احراز هویت و امکانات کامل هنوز باید منتقل و تست شود.
